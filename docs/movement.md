# 路徑移動

從 `Start.bat` 控制台選「路徑移動」，或沿用管理員終端機執行 `fly.py`。後者仍需要先啟動 tunneld。

## 操作

- 地圖右鍵新增標點，或輸入緯度、經度。起始地圖為台北預設座標，並非手機即時 GPS。若要從特定座標起步，可先新增該點並按「跳至下一點」，再新增後續路線。
- 按「開始／繼續」移動；執行中可修改速度、傳送間隔、到點停留時間，按「套用速度與間隔」生效。新間隔從套用時重新計時，不會一次補送積壓座標。
- 「暫停原地」保留路線與最後送出的定位，再按開始即可繼續。
- 「清空路線・停原地」停止移動，清除全部標點與路線，停留在最後送出的座標。新增標點後不會自動移動，須再按開始。這裡的「原地」指清除時的位置，不是回到出發點。
- 「還原真實定位」才會送出定位清除指令。清空與暫停都不會還原 GPS。
- 在地圖標點或左側清單項目按右鍵，可刪除指定標點。刪除會暫停在目前位置並立即更新路線；按開始可沿剩下的目標繼續。其他標點編號保持不變，刪到沒有標點時等待新增。

## 循環與時間

勾選「循環路線」會在最後一點後，沿路移動回第一點，持續重複。第一趟從當前位置走到最後一點；後續每趟包含終點返回第一點的路段。已抵達的標點仍保留供循環與匯出使用。

上方顯示剩餘距離、預估時間與完成趟數。循環模式顯示「本圈剩餘」，因為無限循環沒有全部完成的時間。預估時間包含各路段按傳送間隔取整的步數、中途停留及尚未完成的等待；暫停時凍結。

每次移動距離為「速度 ÷ 3.6 × 傳送間隔」，最後一步會停在目標座標。間隔與速度為目標設定，裝置指令處理延遲可能使實際移動較慢；時間估算未包含此延遲。已送出的裝置指令無法撤回，停止或清空會在當前指令處理結束後套用，不會再排下一步。

## 其他功能

- 標點使用單調遞增編號，抵達或清除路線後不重用，重新開啟視窗才從 1 開始。
- 匯入／匯出每行 `緯度,經度` 的文字檔。匯入是加入現有路線；要替換請先清空。匯出包含已抵達標點。為避免地圖卡頓，匯入後上限為 2,000 點。
- 點左側標點清單可將地圖移至該點；可跟隨目前位置或複製座標。
- 關閉視窗會嘗試還原定位；失敗時會顯示提示。地圖位置代表最後送出或預設座標，不能當作手機已成功接受定位的證明。

## 測試

執行 `myenv\Scripts\python.exe -m unittest discover -s tests -v`。

移動與裝置操作由單一背景控制器依序處理，介面透過訊息更新，不會因快速按停止／開始而產生多個移動執行緒。自動測試使用模擬裝置；實際速度、定位維持與清除仍需連接 iPhone 驗收。
